# Быстрый старт СМЕНА

## Локальная разработка

### 1. Установка зависимостей

#### Windows (PowerShell):

```powershell
# Создание виртуального окружения
python -m venv venv

# Активация
.\venv\Scripts\Activate

# Установка зависимостей
pip install -r requirements.txt
```

#### Linux/Mac:

```bash
# Создание виртуального окружения
python3 -m venv venv

# Активация
source venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt
```

### 2. Настройка базы данных PostgreSQL

#### Установка PostgreSQL

**Windows**: Скачайте и установите с https://www.postgresql.org/download/windows/

**Linux (Ubuntu/Debian)**:
```bash
sudo apt install postgresql postgresql-contrib
```

**Mac**:
```bash
brew install postgresql
```

#### Создание базы данных

```bash
# Подключение к PostgreSQL
psql -U postgres

# В psql:
CREATE DATABASE smena_db;
CREATE USER smena_user WITH PASSWORD 'your_password';
GRANT ALL PRIVILEGES ON DATABASE smena_db TO smena_user;
\q
```

### 3. Настройка переменных окружения

Скопируйте `.env.example` в `.env`:

```bash
cp .env.example .env
```

Отредактируйте `.env` и заполните:

```env
# Получите токен бота у @BotFather в Telegram
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrSTUvwxYZ

# Ваш Telegram ID (можно узнать у @userinfobot)
ADMIN_IDS=123456789

# Настройки базы данных
DB_HOST=localhost
DB_PORT=5432
DB_NAME=smena_db
DB_USER=smena_user
DB_PASSWORD=your_password

# Настройки админ-панели
ADMIN_SECRET_KEY=generate-random-secret-key-here
ADMIN_USERNAME=admin
ADMIN_PASSWORD=admin123

DEBUG=True
```

### 4. Инициализация базы данных

```bash
# Создание миграций
alembic revision --autogenerate -m "Initial migration"

# Применение миграций
alembic upgrade head
```

### 5. Запуск

#### Запуск бота (в отдельном терминале):

```bash
python run_bot.py
```

#### Запуск админ-панели (в другом терминале):

```bash
python run_admin.py
```

Админ-панель будет доступна по адресу: http://localhost:5000

## Первое использование

### 1. Создание Telegram бота

1. Откройте Telegram и найдите @BotFather
2. Отправьте команду `/newbot`
3. Следуйте инструкциям:
   - Введите имя бота (например: "СМЕНА Петрозаводск")
   - Введите username бота (например: "smena_ptz_bot")
4. Скопируйте полученный токен в `.env` файл

### 2. Получение вашего Telegram ID

1. Найдите бота @userinfobot в Telegram
2. Отправьте ему команду `/start`
3. Скопируйте ваш ID в `.env` файл в параметр `ADMIN_IDS`

### 3. Тестирование бота

1. Найдите вашего бота в Telegram по username
2. Отправьте команду `/start`
3. Выберите роль (работодатель или работник)
4. Пройдите регистрацию

### 4. Доступ к админ-панели

1. Откройте в браузере http://localhost:5000
2. Войдите используя:
   - Username: `admin` (или значение из ADMIN_USERNAME)
   - Password: `admin123` (или значение из ADMIN_PASSWORD)
3. Вы увидите дашборд с статистикой

## Основной функционал

### Работодатель

1. **Регистрация**: заполнение анкеты компании
2. **Проверка**: администратор проверяет и одобряет
3. **Создание заявки**: указание всех деталей вакансии
4. **Модерация заявки**: администратор проверяет и одобряет
5. **Поиск работников**: система уведомляет подходящих кандидатов
6. **Просмотр откликов**: работодатель видит профили откликнувшихся
7. **Подтверждение**: администратор подтверждает кандидатов
8. **Оплата**: внесение предоплаты и окончательного расчёта
9. **Оценка**: после смены работодатель оценивает работников

### Работник

1. **Регистрация**: указание города и телефона
2. **Выбор категорий**: выбор интересующих типов работы
3. **Получение уведомлений**: о новых вакансиях
4. **Просмотр вакансий**: поиск подходящих предложений
5. **Отклик**: подача заявки на вакансию
6. **Контакт с администратором**: уточнение деталей
7. **Выход на смену**: выполнение работы
8. **Получение оплаты**: от работодателя напрямую
9. **Получение отзыва**: формирование рейтинга

### Администратор

1. **Модерация работодателей**: проверка и одобрение
2. **Модерация заказов**: проверка заявок
3. **Работа с откликами**: связь с кандидатами, подтверждение
4. **Контроль статусов**: управление жизненным циклом заказа
5. **Просмотр статистики**: дашборд с аналитикой
6. **Управление пользователями**: блокировка, разблокировка
7. **Работа с отзывами**: скрытие некорректных отзывов

## Рабочий процесс

```
1. Работодатель регистрируется
2. Администратор проверяет работодателя → Одобряет
3. Работодатель создаёт заявку
4. Администратор модерирует заявку → Одобряет
5. Система уведомляет подходящих работников
6. Работники откликаются
7. Администратор связывается с кандидатами
8. Администратор подтверждает подходящих → Уведомляет работодателя
9. Работодатель вносит предоплату
10. Работники выходят на смену
11. Администратор переводит заказ в статус "Смена завершена"
12. Работодатель оценивает работников
13. Работодатель оплачивает остаток комиссии
14. Администратор закрывает заказ
```

## Статусы заказа

1. **Создан** (`created`) - работодатель создал заявку
2. **На модерации** (`moderation`) - ожидает проверки администратора
3. **Поиск работников** (`search_workers`) - отправлены уведомления работникам
4. **Подтверждение работников** (`confirm_workers`) - есть отклики, администратор связывается
5. **Ожидание предоплаты** (`prepayment`) - работники подтверждены, ожидание оплаты
6. **Смена началась** (`shift_started`) - работа в процессе
7. **Смена завершена** (`shift_completed`) - работа выполнена, ожидание оценок
8. **Расчёт закрыт** (`payment_completed`) - всё завершено и оплачено
9. **Отменён** (`cancelled`) - заказ отменён

## Команды бота

### Общие команды
- `/start` - начало работы, выбор роли
- `/help` или кнопка "❓ Помощь" - справка

- `/admin` - базовая статистика в боте

## Troubleshooting

### Бот не отвечает

1. Проверьте, запущен ли процесс: смотрите терминал с `run_bot.py`
2. Проверьте токен в `.env` файле
3. Проверьте подключение к базе данных

### Админ-панель не открывается

1. Проверьте, запущен ли процесс: смотрите терминал с `run_admin.py`
2. Проверьте порт (по умолчанию 5000)
3. Проверьте firewall/антивирус

### Ошибки базы данных

1. Убедитесь, что PostgreSQL запущен
2. Проверьте параметры подключения в `.env`
3. Убедитесь, что база данных создана
4. Проверьте, применены ли миграции: `alembic upgrade head`

### Не приходят уведомления работникам

1. Проверьте, что заказ в статусе "Поиск работников"
2. Убедитесь, что есть работники с подходящей категорией и городом
3. Проверьте, не заблокировал ли работник бота
