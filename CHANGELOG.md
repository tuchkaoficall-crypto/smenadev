## [1.0.0] - 2024-01-XX

### Добавлено

#### Telegram Бот
- Регистрация работодателей с проверкой администратором
- Регистрация работников с выбором категорий работы
- Создание заявок работодателями на подбор работников
- Система модерации заявок
- Автоматические уведомления работникам о новых вакансиях
- Система откликов на вакансии
- Профили работников с рейтингом
- Система отзывов о работниках
- Управление статусами заказов
- Уведомления администраторам о новых заявках и откликах

#### Админ-панель
- Дашборд с общей статистикой проекта
- Управление работодателями (модерация, блокировка)
- Управление работниками (просмотр профилей, рейтингов)
- Управление заказами (модерация, изменение статусов)
- Просмотр и управление откликами
- Система аутентификации администратора
- Просмотр финансовой статистики

#### База данных
- Модель пользователей
- Модель работодателей с проверкой
- Модель работников с рейтингом
- Модель заказов со статусами
- Модель откликов
- Модель отзывов с оценками по критериям
- Модель платежей

#### Система рейтингов
- Оценка работников по 5-бальной шкале
- Дополнительные критерии: пунктуальность, ответственность, качество, коммуникация
- Текстовые отзывы
- Автоматический пересчёт среднего рейтинга
- Отображение рейтинга в профиле работника
- Подсчёт завершённых смен

#### Финансовый модуль
- Расчёт комиссии сервиса
- Система предоплаты (50%)
- Отслеживание платежей
- Финансовая статистика в админ-панели

#### Документация
- README.md с полным описанием проекта
- QUICKSTART.md для быстрого старта
- DEPLOY.md для развертывания на VPS
- Комментарии в коде
- Описание API сервисов

### Технологии
- Python 3.10+
- aiogram 3.4.1 (Telegram Bot)
- Flask 3.0.2 (Admin Panel)
- PostgreSQL (Database)
- SQLAlchemy 2.0.27 (ORM)
- Alembic 1.13.1 (Migrations)
- Bootstrap 5 (Frontend)

### Регион запуска
- Петрозаводск, Республика Карелия
