## 📋 Что нужно сделать перед запуском

### 1. Создать бота в Telegram

1. Откройте Telegram и найдите **@BotFather**
2. Отправьте команду `/newbot`
3. Введите имя бота: `СМЕНА Петрозаводск` (или любое другое)
4. Введите username бота: `smena_ptz_bot` (или другой, заканчивающийся на `_bot`)
5. Скопируйте токен, который выдаст BotFather

### 2. Получить ваш Telegram ID

1. Найдите бота **@userinfobot** в Telegram
2. Отправьте ему `/start`
3. Скопируйте ваш ID (число)

### 3. Настроить PostgreSQL

#### Вариант А: Локальная установка PostgreSQL

**Если у вас НЕТ PostgreSQL:**

1. Скачайте PostgreSQL с https://www.postgresql.org/download/windows/
2. Установите с настройками по умолчанию
3. Запомните пароль для пользователя `postgres`

**Создайте базу данных:**

```powershell
# Запустите psql (через меню Пуск → PostgreSQL → SQL Shell)
# Введите пароль когда попросит

CREATE DATABASE smena_db;
\q
```

#### Вариант Б: Использование Docker (если установлен)

```powershell
docker run --name smena-postgres -e POSTGRES_PASSWORD=postgres -e POSTGRES_DB=smena_db -p 5432:5432 -d postgres:15
```

### 4. Обновить файл .env

Откройте файл `.env` в корне проекта и замените значения:

```env
# Telegram Bot Configuration
BOT_TOKEN=YOUR_BOT_TOKEN_FROM_BOTFATHER_HERE
ADMIN_IDS=YOUR_TELEGRAM_ID_HERE

# Database Configuration
DB_HOST=localhost
DB_PORT=5432
DB_NAME=smena_db
DB_USER=postgres
DB_PASSWORD=postgres  # Ваш пароль от PostgreSQL

# Admin Panel Configuration
ADMIN_SECRET_KEY=your-random-secret-key-here-change-this
ADMIN_HOST=0.0.0.0
ADMIN_PORT=5000
ADMIN_USERNAME=admin
ADMIN_PASSWORD=admin123

# Application Settings
DEBUG=True
TIMEZONE=Europe/Moscow

# Commission Settings - Процентная система
PREPAYMENT_PERCENT=50
```

## 🔍 Проверка работы комиссий

Система комиссий работает автоматически:

| Сумма за смену | Процент | Пример |
|----------------|---------|---------|
| < 2500₽ | 5% | 2000₽ → комиссия 100₽ |
| 2500-4500₽ | 10% | 3000₽ → комиссия 300₽ |
| > 4500₽ | 12.5% | 5000₽ → комиссия 625₽ |

Комиссия рассчитывается от **общей суммы оплаты работникам**, а не от оплаты одному работнику.

Пример:
- Оплата одному работнику: 1000₽
- Нужно работников: 3
- **Итого для работников: 3000₽**
- **Комиссия (10%): 300₽**
- **Всего работодатель платит: 3300₽**

## ❌ Решение проблем

### Бот не запускается

**Ошибка: "Invalid token"**
- Проверьте правильность токена в `.env`
- Убедитесь, что нет лишних пробелов

**Ошибка подключения к базе данных**
- Убедитесь, что PostgreSQL запущен
- Проверьте пароль и имя базы в `.env`
- Проверьте, что база данных создана

### База данных не инициализируется

```powershell
# Удалите папку с миграциями и создайте заново
Remove-Item -Recurse -Force .\database\migrations\versions\
alembic revision --autogenerate -m "Initial migration"
alembic upgrade head
```

### Порт 5000 занят (для админ-панели)

Измените в `.env`:
```env
ADMIN_PORT=5001
```

## 📊 Структура работы

### Работодатель
1. Регистрация → Проверка админом
2. Создание заявки → Модерация
3. Поиск работников → Получение откликов
4. Подтверждение кандидатов
5. Оплата (предоплата + финальный расчёт)
6. Оценка работников

### Работник  
1. Регистрация (город + категории)
2. Получение уведомлений о вакансиях
3. Отклик на подходящие
4. Связь с администратором
5. Выход на смену
6. Получение оплаты от работодателя
7. Получение отзыва → Рейтинг

### Администратор
1. Модерация работодателей
2. Модерация заявок
3. Работа с откликами
4. Контроль статусов заказов
5. Блокировка недобросовестных пользователей
