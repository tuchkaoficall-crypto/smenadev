# Функционал создания заявок для работодателей

## Описание
Полный flow создания заявки на подбор работников с inline клавиатурами.

## Процесс создания заявки

### 1. Начало создания
- Кнопка: **"➕ Создать заявку"**
- Проверка: работодатель должен быть зарегистрирован и одобрен (status = APPROVED)
- Если не одобрен - выдается сообщение об ожидании проверки

### 2. Шаги заполнения (состояния FSM)

#### CreateOrder.category
- Выбор категории работы из списка JOB_CATEGORIES
- Inline клавиатура с кнопками категорий (2 в ряд)
- Callback: `job_cat_{category}`

#### CreateOrder.city
- Выбор города из AVAILABLE_CITIES
- Inline клавиатура с кнопками городов
- Callback: `city_{city}`

#### CreateOrder.address
- Текстовый ввод адреса
- Валидация: минимум 5 символов

#### CreateOrder.shift_date
- Выбор даты из календаря (ближайшие 14 дней)
- Inline клавиатура с датами:
  - "Сегодня (DD.MM)"
  - "Завтра (DD.MM)"
  - "DD.MM (день недели)"
- Callback: `date_DD-MM-YYYY`

#### CreateOrder.shift_duration
- Выбор продолжительности смены в часах
- Inline клавиатура: 2, 4, 6, 8, 10, 12 часов (3 в ряд)
- Callback: `duration_{hours}`

#### CreateOrder.workers_needed
- Текстовый ввод количества работников
- Валидация: от 1 до 100

#### CreateOrder.payment_type
- Выбор типа оплаты
- Inline клавиатура:
  - "💰 За смену" - `payment_per_shift`
  - "⏰ Почасовая" - `payment_per_hour`

#### CreateOrder.payment_amount
- Текстовый ввод суммы
- Валидация: от 100 до 100 000 рублей
- **Автоматический расчет комиссии:**
  - Если оплата почасовая: shift_amount = amount × duration
  - Комиссия рассчитывается функцией `calculate_commission(shift_amount)`:
    - < 2500₽ → 5%
    - 2500₽ - 4500₽ → 10%
    - > 4500₽ → 12.5%
  - Показ детального расчета стоимости

#### CreateOrder.description
- Текстовый ввод описания работы
- Валидация: минимум 10 символов

#### CreateOrder.requirements
- Текстовый ввод требований к работникам
- Опционально: можно пропустить через `/skip`

#### CreateOrder.confirmation
- Показ полной информации о заявке:
  - Категория, город, адрес
  - Дата и продолжительность
  - Количество работников
  - Оплата
  - Описание и требования
  - Детальный расчет стоимости
- Inline клавиатура:
  - "✅ Да, всё верно" - `confirm_yes`
  - "❌ Нет, отменить" - `confirm_no`

### 3. Создание заявки
- Вызов `OrderService.create_order()`
- Статус: `OrderStatus.CREATED`
- Уведомление администраторов через `notify_admins_new_order()`
- Показ сообщения об успешном создании
- Возврат в главное меню работодателя

### 4. Отмена создания
- При нажатии "❌ Нет, отменить"
- Очистка состояния FSM
- Возврат в главное меню

## Добавленные inline клавиатуры

```python
# В bot/keyboards/inline.py:
- get_job_categories_keyboard() - категории работ
- get_date_keyboard() - календарь на 14 дней
- get_duration_keyboard() - продолжительность смены
- get_payment_type_keyboard() - тип оплаты
- get_confirmation_keyboard() - подтверждение действия
```

## Расчет стоимости

```python
# Для работодателя показывается:
Оплата за смену: {shift_amount} ₽
Комиссия: {commission} ₽
Итого за 1 работника: {shift_amount + commission} ₽
Всего ({workers_needed} чел.): {total_cost} ₽
```

## Уведомления администраторов

При создании заявки администраторы получают уведомление с:
- Номером заявки
- Информацией о компании
- Деталями заявки
- Inline клавиатурой модерации:
  - "✅ Одобрить" - переводит в статус SEARCH_WORKERS
  - "❌ Отклонить" - переводит в статус CANCELLED
