### ✅ База данных
- **Используется SQLite** для локальной разработки
- База данных создана: `smena_db.sqlite`
- Все таблицы созданы:
  - `users` - пользователи
  - `employers` - работодатели
  - `workers` - работники
  - `orders` - заказы
  - `responses` - отклики
  - `reviews` - отзывы
  - `payments` - платежи

### ✅ Система комиссий
Работает процентная система:
- **< 2500₽** → 5% комиссии
- **2500-4500₽** → 10% комиссии
- **> 4500₽** → 12.5% комиссии

Комиссия рассчитывается от **общей суммы** оплаты всем работникам.

- И все остальные

## Что нужно сделать для запуска

### 1. Создать бота в Telegram

```
1. Откройте @BotFather в Telegram
2. Отправьте: /newbot
3. Введите имя: СМЕНА Петрозаводск
4. Введите username: smena_ptz_bot
5. Скопируйте токен
```

### 2. Получить ваш Telegram ID

```
1. Откройте @userinfobot в Telegram  
2. Отправьте: /start
3. Скопируйте ваш ID
```

### 3. Обновить .env файл

Откройте `C:\Users\tuchk\Downloads\CMENA\.env` и замените:

```env
BOT_TOKEN=YOUR_TOKEN_HERE  ← Вставьте токен от BotFather
ADMIN_IDS=YOUR_ID_HERE     ← Вставьте ваш Telegram ID
```

Остальные настройки уже готовы!
